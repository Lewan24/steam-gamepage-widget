# Product

## Platform

web

## Purpose and users

Bloggers and game developers create an interactive Steam store game widget from an App ID and embed it on their own websites.

## Stack

React, TypeScript, Vite; a small Node.js server fetches public Steam data without an API key. This is a separate project beside the untouched Java reference.

## Capabilities and constraints

No generator accounts. Live game data, artwork, themes and customization; iframe output. Wishlist links open Steam, where adding to a user's wishlist requires their Steam account. Hosting needs Node.js and outbound HTTPS. No database.

## Confirmed direction

Polish editor, modern minimal interface, code-first implementation selected by user.
